## The letter: A (coffee)

The bounty asks for one letter: **A** for coffee, **B** for tea. This entry
sends **A**.

Coffee is the louder of the two drinks. It is dark and bitter, the thing
people reach for first thing in the morning when they need to wake up and
get going. Tea is gentle and quiet; coffee shouts. The judge weighs
vividness first, and the bolder stance is the more vivid answer. "A" also
happens to be the first letter and the top grade, so it reads as the
natural first pick — a complete answer that needs no word beside it.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly one byte,
the letter `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
No network, no randomness: every run produces the same single byte, and
the program checks on disk that the file is exactly 1 byte before it
finishes.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — one byte, `A`, no trailing newline.
